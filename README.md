# LottoPicker (Android)

로또 6/45 번호 생성기 — 역대 3등 이상 미당첨 + 최근 회차와 1개 중복 조건의 무작위 세트 생성.

## 빌드

GitHub Actions가 `main` 브랜치에 푸시되면 자동으로 APK를 빌드합니다.

### 빌드된 APK 받기
1. 이 레포의 **Actions** 탭으로 이동
2. 가장 최근에 성공한 워크플로우 클릭
3. 페이지 하단 **Artifacts** 섹션에서 `LottoPicker-apk` 다운로드
4. zip 풀면 `*.apk` 파일이 있음

## 폰에 설치

1. APK 파일을 폰으로 전송 (카톡, 구글 드라이브, USB 등)
2. 폰에서 APK 탭 → "출처를 알 수 없는 앱 설치 허용"
3. 설치 완료

## 자동 업데이트

- 앱을 켜면 캐시에 있는 마지막 회차 이후의 신규 회차를 dhlottery API에서 자동으로 받아옵니다
- 인터넷이 없거나 API가 막혔다면 "회차 추가" 입력란으로 수동 입력 가능 (형식: `1224 5 12 18 24 33 41 / 7`)

## 기능

- 5/10/20/30 세트 무작위 생성 (역대 3등 이상 안 나온 조합)
- 최근 회차와 정확히 1개 번호 중복
- "패턴 제거" 체크박스: 3연속/같은10단위5+/짝수홀수전부/N의배수/등차수열 거름
- 6개 번호 입력 → 역대 1~5등 당첨 이력 조회
